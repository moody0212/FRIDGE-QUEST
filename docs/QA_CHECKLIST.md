# 🧪 FRIDGE QUEST QA 테스트 체크리스트 (QA Checklist)

> **기준 문서**: `PRD.md` (제5장 예외 처리 및 제6장 완료 조건)  
> **용도**: 스프린트 개발 완료 후 기능, 엣지 케이스 및 7대 레시피 품질 룰 전수 검증용  
> **문서 버전**: v1.2.0 (TC-101 ~ TC-403 총 28개 시나리오 전 항목 Pass 완료)  
> **검증일**: 2026-08-27

## 1. 입력 및 폼 유효성 검사 (Sprint 1)

| No. | 테스트 시나리오 | 기대 결과 | 상태 (Pass/Fail) |
| :--- | :--- | :--- | :--- |
| **TC-101** | 기본 재료 '대부분 있어요' 클릭 | 10개 기본 재료가 모두 체크됨 | [x] Pass |
| **TC-102** | 전체 선택 후 특정 재료(예: 김치) 개별 해제 | 김치만 체크 해제되고 나머지 9개 유지됨 | [x] Pass |
| **TC-103** | 기본 재료를 0개 선택하고 진행 | 오류 없이 정상 진행 가능 | [x] Pass |
| **TC-104** | 냉털 재료 0개 상태에서 QUEST 생성 클릭 | AI 미호출, `❗ 냉털할 식재료를 2개 이상 입력해주세요.` 빨간색 에러 노출 | [x] Pass |
| **TC-105** | 냉털 재료 1개 상태에서 QUEST 생성 클릭 | AI 미호출, `❗ 재료가 하나 더 필요해요! 냉털 식재료를 2개 이상 입력해주세요.` 노출 | [x] Pass |
| **TC-106** | 냉털 재료 20자 초과 입력 시도 (예: 21자 문자열) | 목록에 추가되지 않고 `❗ 재료 이름은 20자 이내로 입력해주세요.` 노출 | [x] Pass |
| **TC-107** | 이미 등록된 재료 중복 입력 시도 (예: '계란' 중복 추가) | 목록에 추가되지 않고 `❗ 이미 추가된 재료예요.` 노출, 기존 상태값 유지 | [x] Pass |
| **TC-108** | 냉털 재료 10개 초과 입력 시도 (11번째 재료 추가) | 목록에 추가되지 않고 `❗ 냉털 재료는 최대 10개까지 입력할 수 있어요.` 노출 | [x] Pass |
| **TC-109** | 재료 상태를 선택하지 않고(`상태를 선택하세요`) QUEST 생성 클릭 | AI 미호출, 해당 드롭다운 강조 및 `❗ 모든 냉털 식재료의 상태를 선택해주세요.` 노출 | [x] Pass |
| **TC-110** | 재료 삭제 (X 버튼) 클릭 | 해당 재료 및 상태값이 목록에서 즉시 제거됨 | [x] Pass |
| **TC-111** | 조리시간 미선택 시 기본값 확인 | '20분 이내'가 기본값으로 적용됨 | [x] Pass |

## 2. AI 추천 및 비즈니스 룰 검증 (Sprint 2 & 레시피 품질 7대 룰)

| No. | 테스트 시나리오 | 기대 결과 | 상태 (Pass/Fail) |
| :--- | :--- | :--- | :--- |
| **TC-201** | 요리 추천 개수 확인 | 정확히 1개의 요리 및 조리법만 반환됨 | [x] Pass |
| **TC-202** | 🟡 (시들거나 물러졌어요) 재료 우선 구조 | 🟡 재료가 `rescueTarget`으로 지정되고 요리의 메인 재료로 활용됨 | [x] Pass |
| **TC-203** | 🔴 (상태가 많이 안 좋아요) 재료 안전 안내 | 강제 사용되지 않으며 `⚠️ 상태가 좋지 않은 식재료입니다...` 주의 문구가 표시됨 | [x] Pass |
| **TC-204** | 미체크 기본 재료 사용 여부 | 미체크 기본 재료는 `basicUsed`에 들어가지 않고 `extraNeeded`에 표기됨 | [x] Pass |
| **TC-205** | 입력하지 않은 추가 핵심 재료 사용 | `extraNeeded`에 명시되고, 추가 재료가 없거나 적은 요리가 우선 추천됨 | [x] Pass |
| **TC-206** | 조리법 단계 수 검증 | 조리법이 최대 5단계(`STEP 1 ~ STEP 5`) 이내로 생성됨 | [x] Pass |
| **TC-207** | 조리법 재료 정합성 검증 | 조리법 본문에 언급된 모든 재료가 재료 목록(냉털/기본/추가)에 빠짐없이 존재함 | [x] Pass |
| **TC-208** | 조리 완료된 음식 성격 판단 | '엄마가 만든 파프리카감자샐러드' 등 완성된 음식은 생재료 볶음 과정에서 일괄 제외됨 | [x] Pass |
| **TC-209** | 부자연스러운 모든 재료 억지 섞기 방지 | 입력된 모든 재료를 한 요리에 억지로 다 넣지 않고 어울리는 재료 조합만 요리화 | [x] Pass |
| **TC-210** | 완성된 음식 곁들임 TIP 제안 | 완성된 음식은 억지 볶음 대신 💡 TIP 카드로 곁들여 먹기 안내 표시 | [x] Pass |
| **TC-211** | 재료별 적절한 조리 동작 적용 | 범용 문장 대신 양파(썰기), 삼겹살(자르기), 계란(풀기) 등 고유 동작 적용 | [x] Pass |
| **TC-212** | 한국어 조사 괄호 표기 제거 | `(을/를)`, `(이/가)` 등 괄호 표기 없이 받침에 알맞은 올바른 조사 연결 | [x] Pass |
